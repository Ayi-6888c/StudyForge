## 为什么做这个项目

专升本备考经常分散在政策网页、课程视频、群聊、题目和个人计划中。拾光学习希望把“我能报什么、今天学什么、做完如何订正”放回同一张安静的书桌上。

项目从湖北软件技术学生的真实使用场景开始，用 AI 辅助开发。代码通过回归测试不代表招生资料、教学内容或主观评分已经完成专家审核。欢迎带着真实问题参与，而不是只增加功能数量。

| 课程与笔记 | 自有视频课程目录、章节记录、笔记与任务关联 | 视频托管和跨设备同步 |

| 本地账户 | 密码、恢复码、会话、各学生独立数据库、导出备份 | 公网身份服务与云同步 |

- 48所湖北学校、709个院校专业参考项目、811项专科名称词典。
- 338项结构化专业对应规则、433项具名专业课信息、275个两项齐备的参考项目；434项仍有资料缺口。

## 三分钟启动

需要 Python 3.11 或 3.12。基础网页服务没有第三方运行依赖。

```sh
python app/app.py
```

启动后会在本机随机端口打开浏览器。首次启动自己设置账号；没有预置真实用户、密码、学校目标或学习记录。

只启动服务、不自动打开页面：

```sh
python app/app.py --no-browser --port 8765
```

然后访问 `http://127.0.0.1:8765/`。若端口被其他程序占用，换一个端口，或不指定端口使用自动分配。

### 数据可以放在别的盘

默认保存在 `app/data/`，并由 `.gitignore` 排除。可以在启动前设置 `STUDYFORGE_DATA_DIR`：

```powershell
# Windows PowerShell
$env:STUDYFORGE_DATA_DIR = 'D:\StudyForge-data'
python app/app.py
```

Linux/macOS：`STUDYFORGE_DATA_DIR="$HOME/.local/share/studyforge" python app/app.py`。详情见[迁移与备份](docs/MIGRATION.md)。

### C代码检查的公开版默认值

默认只做静态检查，不运行提交的程序。只有在自己电脑、确认代码可信并配置编译器后，才显式开启：

```powershell
$env:STUDYFORGE_ENABLE_CODE_EXECUTION = '1'
python app/app.py
```

这不是沙箱。多个本地学习账号也不构成操作系统隔离；请不要处理他人提供的不可信代码。云端评测需要另外设计隔离执行服务。这个公开源码副本的默认值不会修改原有个人安装版。

## 检查和构建

```sh
python scripts/run_checks.py
python scripts/release_check.py
python scripts/build_source_archive.py
```

核心测试不调用真实AI、不抓取外网、不发送Windows通知。可选[浏览器测试与Windows打包](docs/DEVELOPMENT.md)另外配置依赖。GitHub Actions工作流已提供；上传前的本地检查不等于GitHub托管运行已经通过。

## 如何参与

优先欢迎：可复现的使用故障、带官方来源和适用年份的资料勘误、教师审核、不同省份独立规则包、无障碍与测试改进。提交真实学习记录前请删除姓名、账号、恢复码和作业等私有内容。

## 项目边界

不承诺录取、不预测官方日期或分数线、不把旧年当当年、不把“相关专业”自动推成可报、不把内置资料问答包装成大模型。当前版本不自动上传学习记录、不收款、不内置广告。未来商业服务和服务器建设另行设计。
