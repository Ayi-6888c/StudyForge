# Third-party notices and source boundaries

## Software and assets

- Original code and documentation use [Apache-2.0](LICENSE), with attribution in [NOTICE](NOTICE). External works are not relicensed.
- Code, interface and training content were developed with AI assistance. An independent rights audit has not been completed.
- Core code uses Python's standard library. Source archives do not bundle Python, compilers, Windows components, model weights, DLLs or installers.
- Optional pywin32, PyInstaller and Playwright retain their own licenses. Binary releases require separate review of bundled runtimes/dependency notices.
- Project icons/illustrations are locally drawn graphics. Screenshots use isolated synthetic learners, not real student records.

## Admissions and exercises

`app/hubei_catalog.json`, `app/exam_packs.json` and `app/news_registry.json` contain public admissions facts, structured metadata and official links. Reference years, review states and gaps are part of the data; retain them when quoting.

School publications, websites, textbooks and other third-party works keep their own rights. The repository does not bundle downloaded official PDFs, complete textbooks or paid third-party question banks. Review redistribution/commercial rights separately; linking does not confer them.

`app/question_bank.json` contains original/AI-assisted exercises, **not official past papers**. Engineering tests do not substitute for teaching review. Teachers should check wording, equivalent answers and marking criteria. Report specific rights/source concerns for correction or removal.
