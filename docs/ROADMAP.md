# Roadmap: validate usefulness before expanding

## Current candidate

Local goals, route-aware planning, practice/revision, course notes, official-source discovery, reference Q&A and feedback. Release preparation adds documentation, private-data exclusions, repeatable tests, checks and opt-in code execution.

## Priorities

1. **Accuracy:** close Hubei evidence gaps, obtain teacher review, strengthen positive/negative cases and track annual changes/broken links.
2. **Learner trials:** observe students independently complete goal → answer → feedback → revision; measure friction/time. Registrations do not prove learning.
3. **Engineering:** separate HTTP/service layers, improve database lifecycle, errors, accessibility and cross-platform tests.
4. **Second province:** independently verify its exam system and one representative route. Do not copy Hubei into a nationwide claim.
5. **Hosted foundations:** identity, isolated judging, queues, recovery, consent and usage limits before connecting AI.

## Commercial hypotheses

Keep basic reference access and personal-record export available. Possible services include synchronization, reviewed packs, human marking and metered AI. There is no live payment system or promised revenue, retention or outcome. External content rights remain separate.

## Open-source support applications

Describe actual publication, maintenance and use. Do not invent stars, downloads, learners, contributors, reviews, awards or acceptance. Disclose AI assistance without replacing maintainer responsibility. Publishing a repository does not guarantee funding or subscription support.
