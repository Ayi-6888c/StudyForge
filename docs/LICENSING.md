# Apache-2.0 and licensing boundaries

The maintainer chose Apache License 2.0 on October 23, 2026. [LICENSE](../LICENSE) contains the complete official text; [NOTICE](../NOTICE) records attribution.

Original application code, project documentation and interface implementation use Apache-2.0. Usage, modification, redistribution and commercial use remain subject to the full terms, including applicable license, attribution and change notices. Patent, trademark and warranty provisions follow the formal text.

Official text: <https://www.apache.org/licenses/LICENSE-2.0.txt>. Release tooling checks its normalized SHA256, rejecting empty, truncated or example licenses.

External policies, school publications, textbooks and websites are not relicensed by quotation or links. Source facts/quotations retain provenance; dependencies retain their own licenses. See [third-party notices](../THIRD_PARTY_NOTICES.md).

Future paid hosting or human review can be designed separately; charging does not remove obligations attached to existing Apache-2.0 material. New components and external learning content need individual rights review.
